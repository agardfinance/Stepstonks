A Temu-inspired WooCommerce theme with flash deals, countdown timers, and bold orange branding.

== Description ==

Stepstonks Temu is a high-conversion WooCommerce theme inspired by Temu's design language:

* Bold orange/red primary palette
* Flash Deals section with countdown timer
* Sold progress bars on every product card
* Horizontal scroll product carousels
* Category icon grid
* Promo banner rows
* Hero banner with side cards
* Sticky product header on mobile
* Mini cart sidebar
* AJAX Add-to-Cart
* Fully responsive — mobile-first
* WooCommerce 8.x compatible
* Customizer options: colors, hero text, flash deal timer, sticky ATC toggle

== Installation ==

1. Upload the `stepstonks-temu` folder to `/wp-content/themes/`
2. Activate from Appearance → Themes
3. Activate WooCommerce plugin
4. Go to Appearance → Customize → Stepstonks Temu Options to configure

== Frequently Asked Questions ==

= Does it require WooCommerce? =
Yes, WooCommerce must be installed and activated.

= Can I change the colors? =
Yes, go to Appearance → Customize → Stepstonks Temu Options.
